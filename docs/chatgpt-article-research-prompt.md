# ChatGPTチャットモード用：比較記事リサーチ依頼テンプレート

このテンプレートをChatGPTの**チャットモード**へ貼り付け、返答をそのまま保存してCodexへ渡す。ChatGPTには調査と候補選定を任せ、Codexは返答の検証・記事化・表示確認を行う。

## 依頼文

```text
あなたは商品比較記事のリサーチ担当です。以下の条件を厳守し、調査結果を最後の出力フォーマットで返してください。

【目的】
比較サイト「くらべる商品メモ」向けに、商品選定から記事化に必要な一次情報を調査する。

【比較テーマ】
カテゴリ：{{カテゴリ}}
読者の悩み・用途：{{用途}}
候補が未指定の場合は、現行商品・型番が公式ページで確認でき、共通仕様を比較できる2商品を選定する。

【調査の順序】
1. 商品A/Bを選定し、正式名称・型番・選定理由を確定する。
2. メーカー公式ページで、商品名・型番・比較可能な仕様・公式画像URLを確認する。
3. 楽天市場で、商品名と型番が一致する商品詳細ページを各1件探す。
4. Amazon.co.jpで、商品名と型番が一致する商品詳細ページまたはASINを各1件探す。
5. X、YouTube等で、対象型番が本文または動画タイトルから確認できる利用者投稿を探す。見つからない場合は「該当なし」と記録する。
6. 公式情報だけを比較表と結論の根拠にし、口コミ・SNSは参考情報として分離する。

【URL・画像の条件】
- 推測URL、検索結果URL、別型番・後継機・シリーズ全体のURLを商品固有URLとして扱わない。
- 公式画像URLは、実際に対象商品の画像であることを確認する。確認できない場合は「確認不可」とする。
- 楽天は商品詳細ページURL、Amazonは https://www.amazon.co.jp/dp/ASIN または /gp/product/ASIN の形式を優先する。
- 楽天アフィリエイトURLは、楽天アフィリエイト公式UIで生成した完全URLが確認できる場合だけ記載する。生成できない場合は「未生成」とする。
- AmazonアフィリエイトURLは、商品URLにトラッキングID {{AmazonストアID}} を付けた完成形を示す（例：?tag={{AmazonストアID}}）。
- URLは省略せず、リンク先の商品名・型番・ショップ名・ASINを併記する。

【SNSの採用条件】
- match=model：投稿本文・動画タイトル等に対象型番が明記されている。
- match=series：シリーズ名まで確認でき、型番は確認できない。
- match=brand：ブランド一般のみ。比較記事の埋め込み候補にはしない。
- 埋め込み候補はmodelまたはseriesのみ。投稿URLが存在しない、削除済み、対象商品を確認できない場合は採用しない。

【禁止事項】
- 公式情報にない数値・機能・価格・在庫を推測で補わない。
- SNSや口コミを比較結論の根拠にしない。
- 見つからない情報を架空のURLや「確認済み」で埋めない。

【最終出力フォーマット】
# 調査結果
調査日（日本時間）：

## 2. 公式情報（比較根拠）

|---|---|---|
| 公式表示名 | | |
| 型番 | | |
| 仕様1（単位付き） | | |
| 仕様2（単位付き） | | |
| 仕様3（単位付き） | | |
公式URL（A）：

公式画像URL（A）：
公式画像URL（B）：
確認できなかった項目：

## 3. 販売リンク
### 楽天
A：商品詳細URL／商品名・型番一致／ショップ名／公式UI生成アフィリエイトURL
B：商品詳細URL／商品名・型番一致／ショップ名／公式UI生成アフィリエイトURL

## 4. SNS・口コミ（比較根拠にはしない）

```

## 返答を受け取った後の固定手順

1. ChatGPTの返答を改変せず、`research/inbox/YYYY-MM-DD-<slug>.md` に保存する。
2. Codexへ「この調査結果を記事化」と依頼する。
3. Codexは、返答内の公式URL・画像・楽天/Amazon URL・SNS投稿を個別に検証する。
4. 検証済みデータだけをseed、購入リンク台帳、画像、SNS埋め込みへ反映する。
5. ローカル表示で商品画像、比較表、購入カード、楽天/Amazonボタン、SNS埋め込みを確認する。
6. 未確認項目が残る場合は公開せず、残件として報告する。
7. ユーザーが本番公開を指示した後にだけデプロイし、デプロイ完了と確認URLを報告する。

ChatGPTの返答を直接取得できない場合があるため、返答の貼り付けを正式な受け渡し工程とする。これにより、依頼済み・返答受領済み・記事反映済み・デプロイ済みを混同しない。

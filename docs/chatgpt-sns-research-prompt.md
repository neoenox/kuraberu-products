# ChatGPTチャットモード用：SNS感想だけを調査する依頼文

以下をChatGPTの**チャットモード**に貼り付ける。Workモードには貼り付けない。

```text
以下の商品について、SNS・動画での実利用者の感想だけを調査してください。

商品A：{{商品名・モデル名・型番}}
商品B：{{商品名・モデル名・型番}}
調査日（日本時間）：{{YYYY-MM-DD}}

【対象】
- X、YouTube、TikTokなどの公開投稿
- 実際の利用者による使用感、開封、購入後の感想

【採用条件】
- 投稿本文・動画タイトル・説明欄で商品名またはモデル名が確認できる
- 投稿URLを開いて内容を確認できる
- 別型番・後継機・別カラー限定モデルと混同しない
- 店舗、メーカー公式、広告、PR、買取、キャンペーン投稿ではない
- 商品の感想が実際に書かれている
- 色別SKUやJANコードの記載は必須にしない

【除外条件】
- ブランド名だけで商品を特定できない
- シリーズ名だけで複数モデルのどれか分からない
- 商品紹介だけで利用者の感想がない
- 販売ページ、検索結果ページ、転載まとめ
- 削除済み・非公開・URL不明の投稿

【重要】
- 見つからない場合は、無理に埋めず「0件」と返す
- 件数を増やすために別商品や別型番を混ぜない
- 口コミの内容を仕様や比較結論として扱わない
- 投稿本文を長文転載せず、要点だけ要約する

【出力形式】
## 調査結果
調査日：

### 商品A
採用件数：
| provider | 投稿URL | 投稿者 | 投稿日 | 商品一致の根拠 | 感想の要約 | match |
|---|---|---|---|---|---|---|

### 商品B
採用件数：
| provider | 投稿URL | 投稿者 | 投稿日 | 商品一致の根拠 | 感想の要約 | match |
|---|---|---|---|---|---|---|

### 埋め込み用JSON
採用投稿がある場合のみ、次の形式で出力してください。
{
  "embeds": [
    {
      "provider": "x または youtube",
      "url": "",
      "title": "",
      "match": "model または series",
      "purpose": "実利用者の感想の参考情報",
      "tone": "positive / negative / mixed",
      "autoload": true,
      "compact": true
    }
  ]
}

採用投稿が0件の場合は、必ず次だけを返してください。
{
  "embeds": []
}
```
